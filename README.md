# Blackboard - Resource & Link Library System 📚

เว็บแอปพลิเคชันสำหรับจัดเก็บ คัดเลือก และแชร์ Link / Resources ร่วมกันระหว่างผู้ใช้ทุกคนแบบ Real-time พร้อมพรีวิวหน้าเว็บทันที

## ✨ คุณสมบัติหลัก (Features)

1. **ระบบคัดเลือกสถานะ "ใช้" / "ไม่ใช้" (Curation & Status Toggle):**
   - ผู้ใช้สามารถกดปุ่มสลับสถานะของงานแต่ละชิ้นได้ทันที
   - แถบตัวกรอง (Filter Tabs) ช่วยให้ดูเฉพาะรายการ "ใช้", "ไม่ใช้" หรือ "ทั้งหมด" พร้อมตัวเลขนับจำนวน
   - เมื่อเชื่อมต่อ Supabase ทุกคนในทีมที่เปิดหน้าเว็บอยู่จะเห็นสถานะเปลี่ยนพร้อมกันทันที (Realtime Subscriptions)

2. **เพิ่มงานได้สะดวกรวดเร็ว (Quick Add):**
   - ตั้งชื่อหัวข้อ (Title) เพื่อให้ดูและค้นหาง่าย
   - กรอก Link ปลายทาง โดยระบบจะตรวจจับ Favicon และชื่อโดเมนเพื่อทำ Live Preview ขนาดเล็กให้ดูทันทีขณะกรอก
   - เลือกหมวดหมู่ (Design, Development, Documentation, Resources, General)
   - เพิ่มคำอธิบายเพิ่มเติมได้

3. **แสดงหน้าพรีวิว (Live Website Preview):**
   - คลิกที่ Thumbnail หรือปุ่ม "ดูหน้า Preview" เพื่อเปิดหน้าต่างแสดงตัวอย่างเว็บไซต์ได้โดยตรง
   - มีปุ่ม "เปิดในแท็บใหม่" สำหรับเข้าสู่ URL ทันที

4. **ค้นหาฉับไว (Instant Search):**
   - มีช่องค้นหาที่กรองตามชื่อหัวข้อ คำอธิบาย ลิงก์ และหมวดหมู่ได้แบบทันใจ

5. **สถาปัตยกรรม 2 โหมด (Supabase Cloud + Local Demo Mode):**
   - **โหมดทดลองใช้ (Demo Mode):** บันทึกข้อมูลลง LocalStorage ทันทีโดยไม่ต้องตั้งค่าใดๆ
   - **โหมดเชื่อมต่อ Supabase (Real-time Cloud):** เพียงกดที่ปุ่มสถานะด้านบนขวา แล้วใส่ URL และ Key ก็จะสลับไปใช้ฐานข้อมูล Cloud ทันที

## 🚀 วิธีติดตั้งฐานข้อมูล Supabase

1. สมัครหรือเข้าสู่ระบบที่ [Supabase.com](https://supabase.com) และสร้าง New Project
2. ไปที่เมนู **SQL Editor** ทางด้านซ้าย
3. คัดลอกโค้ดจากไฟล์ `supabase_schema.sql` ในโปรเจกต์นี้ ไปวางแล้วกด **Run**
4. ไปที่ **Project Settings -> API** นำค่า:
   - `Project URL`
   - `Project API Keys (anon public)`
5. ใส่ค่านั้นลงในไฟล์ `config.js` หรือกดคลิกที่ปุ่มสถานะการเชื่อมต่อบนหน้าเว็บเพื่อกรอกได้โดยตรง

## 💻 วิธีเปิดใช้งานบนเครื่อง

เนื่องจากเป็น Web Application มาตรฐาน คุณสามารถเปิดใช้งานได้หลากหลายวิธี เช่น:

### วิธีที่ 1: เปิดผ่าน Browser ได้โดยตรง
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที

### วิธีที่ 2: รัน Local Server ด้วย Python
```bash
python3 -m http.server 3000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
